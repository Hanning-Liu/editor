# 网页 Chat 本地使用

## 启动与访问

在此目录执行 `bash start-local.sh`，然后打开 http://127.0.0.1:3002 。从项目列表进入项目，点击左侧 **Chat**。

- 源码：`editor-src/`，上游固定为 `7d45390fd49bc7700402e4adaa5b6936a50594bc`。
- 网页使用现有 `pascal-home/data/pascal.db`，CLI 与源码版读写同一场景库。
- 本地 Chat 服务 `127.0.0.1:18081`；Qwen MLX `127.0.0.1:18080`。
- 对话和工具记录：`chat-data/<sceneId>.json`；日志：`editor-dev.log`、`chat-server.log`。
- 首次从零准备源码：在 `editor-src/` 执行 `bun install --frozen-lockfile` 和 `bunx turbo run build --filter=editor^... --env-mode=loose`。

## 使用

在空白项目中输入“画一个4米×3米的客厅”；继续“在南墙加一扇0.9米宽的门”。
家具示例：“搜索沙发，在房间中心放置一张合适的沙发”；然后“将这张沙发沿X正方向移动0.5米”。方向或尺寸不明确时应先明确。

当前按需提供82项正常建模工具的完整参数，模型可用 discover_tools 自主选择、加载；read_pascal_resource 可读取原生工具指南与设计规范。目录家具与自定义 Three.js / Blender 建模均可用。家具操作前适配层会按目录或代码模式提交局部 design_brief，模型也可自行提供完整设计说明。工具执行记录可以展开检查参数和结果。修改由 Pascal 自动保存。刷新后恢复当前场景的聊天记录。停止会取消后续推理和调用，已经完成的操作继续保留。

模型只操作当前场景；节点删除、复制、批量编辑、撤销重做和导出均可用。新建/删除项目、切换场景、清空及模板替换留在项目管理边界内；get_project_status 也限定当前场景，避免其隐含的切换行为。图形代码通过本地编译器执行，不向模型提供系统 Shell。为防止本地模型并发抢占，同一时刻仅执行一个 AI 任务。切换项目仅断开聊天显示连接，后台任务会继续；需要取消时点击“停止”。

## 边界

这是单机开发模式，网页服务只监听回环地址。默认家具目录和部分资源仍可能访问网络；本地模型推理不代表全部资产已经离线。云端 Architect、Studio 渲染和图像生成不包含在此实现内。

MCP 修改会通过场景 SSE 刷新画布。执行 AI 操作时建议等待完成再做手动修改；若同时编辑导致版本冲突，任务会停止或编辑器显示冲突提示，不能强制覆盖。

Qwen 服务可通过环境变量 `LOCAL_QWEN_URL` 和 `LOCAL_QWEN_MODEL` 配置后重启 Chat 服务。第一版显示步骤级状态，模型最终回复整段返回。

当前模型使用步骤级事件提示；一轮含多个工具调用的任务通常需要几十秒到数分钟。最近两轮成功对话会连同新读取的场景摘要提供给模型，完整记录仍保存在本地文件。失败或已停止的轮次不会当作成功上下文重放。

后端会检查明确的编辑请求是否产生了成功的编辑工具调用；模型若只返回“已完成”但没有执行依据，会继续要求执行，超限则报告未确认修改。模型回复仍应结合执行记录、检查结果和实际画布核对。

## Chat 控件（2026-11-09）

刷新源码版页面即可使用新操作条：

- **插件**：房间与门窗、屋顶、家具布局、颜色与材质、楼层与结构、编辑与导出、自定义建模、视觉与图片分析、场景检查九组，场景检查始终启用。关闭编辑组后，本轮模型不会获得对应修改工具。这是本地 Chat 工具组；官方第三方场景插件仍由 Pascal 的 Plugins 面板管理，未实现任意插件代码的运行时安装。
- **附件**：PNG/JPEG/WebP、PDF、TXT/Markdown/JSON/CSV。每条最多4个，单个最多8 MB；文本最多64 KB。PDF通过本机Poppler提取前3页文字并渲染为图片（其余页不会发送）。附件存于 `chat-attachments/<sceneId>/`，随消息保存引用；本机模型可读取图片，最近两轮成功对话的附件会继续进入上下文。
- **上下文详情**：最近一次实际输入、累计输入/输出、服务报告的缓存和推理token、场景版本与节点分类、本轮工具和附件。未报告的指标显示“未报告”，不能视为0。累计用量只包含本功能上线后拿到usage的调用，中断请求可能未计入。
- **模型**：来自真实服务配置及 `/v1/models` 的可用性结果。当前只有本地Qwen3.8接好，未添加或虚构云端模型。需要多个本地模型时，复制 `local-models.example.json` 为 `local-models.json`，填入各自真实的本机OpenAI兼容服务地址和模型ID后重启Chat服务。浏览器不接收模型服务地址或密钥。
- **推理**：快速=不启用思考、上限1800 tokens；标准=启用思考、上限4096；深入=启用思考、上限8192。上限包含生成的思考和最终回复，不是保证使用量。当前MTP推测解码不支持精确thinking_budget，因此没有伪造该参数，也不把这三个档位称为官方Architect档位。

模型、推理、插件设置按场景保存在聊天记录中，刷新后恢复，作用于下一条消息；附件移除仅从当前草稿取消，不会删除已发送消息中的文件。

模型配置上限262144来自权重的config.json，并非这台机器已实测可承载的上下文容量。当前场景仍通过MCP读写，新增控件不改变几何引擎。开发模式仍可能出现上游React渲染告警，操作条已避开其提示浮层。

验收结果见 `controls-tests/api-result.json`、`model-result.json`、`ui-result.json`、`ui-send-result.json`。测试包含本地Qwen实际读取图片4827与文本5193、标准思考模式运行、PDF读取范围、插件工具隔离和网页设置保存。

## 稳定性与屋顶修复（2026-11-09）

- 旧验收场景中的22条开发消息保留并标记，默认折叠；不再作为用户的成功历史传给模型。用户自己的屋顶请求和后续回复完整保留。
- 刷新、切换页面或浏览器连接断开不会自动取消任务。后台按场景保存运行状态；重开页面后可继续查看。停止按钮在后端确认接收任务后可用，避免请求还未登记就发出取消的竞态。
- 取消、超时、服务中断记录不同原因，并以系统状态显示；模型输出截断、参数错误、模型服务错误显示中文解释，原始诊断可展开查看。已成功重试的同名工具不再作为未解决错误挂在最终回复后。
- 服务重启时把遗留运行标为中断，不自动重放编辑。若确需继续，先核对当前模型，再发送新的指令。
- 插件新增“屋顶”，提供原生create_roof，可按现有顶层轮廓生成屋顶；本次实测双坡屋顶，40°坡度、平面挑檐0.3m，保留墙和家具。工具会拒绝重复生成已经存在的屋顶。
- 屋顶放在单独的Roof层。选中Ground floor时，上层屋顶会因编辑视图被隐藏；点击楼层列表里的Roof查看完整屋顶。

当前场景613bfb3b5f9a已保存为版本5。见 reliability-tests/roof-result.json、stop-result.json 和 roof-visible.png。


## 全量正常建模工具升级（2026-11-09）

- 当前原生 MCP 清单89项，正常工具82项；另有 discover_tools、read_pascal_resource 两个接入层辅助工具。模型可自主查询所有已启用组的工具，完整 schema 不再裁剪。大型工具成功使用后释放其参数定义，需要时再次加载；调用权限仍保留。
- 项目边界7项：create_project、delete_scene、load_scene（后台专用）、clear_scene、create_from_template、create_house_from_brief、photo_to_scene。图片分析仍可用，通过正常建模工具写入现有场景。
- 后端通过 local-mcp.ts 启动独立 Bun MCP 进程，使用现有 SQLite 场景库；不再依赖原 CLI MCP 的无渲染配置。启动脚本检查并构建修改过的 MCP 包。
- view_scene 使用原生视角规划及编辑器离屏渲染，在单独无自动保存的浏览器页面捕获；图片保存为附件并实际发回 Qwen。资产预览支持本地资源相对路径。旧项目缺少 projectId 时也可截图。
- 图片工具通过 MCP sampling 请求本地 Qwen，实际返回并校验 JSON；attachment:<附件ID> 可引用上传图片或 PDF 的首个预览页。照片推测尺寸不作为实测，尺寸依据应来自用户标注、图纸或场景测量。
- Three.js 编译通过本地子进程（20秒期限），Blender 使用本机 /Applications/Blender.app/Contents/MacOS/Blender。author_scene 的 module+adapter 也有独立执行进程。此配置是本地编译执行环境，不宣称是安全沙箱。add_object 的 piece 文字生成服务未配置，可使用代码路径；author_scene 的 payloadFile 读取器未配置，可使用 payload 或 module+adapter。
- 截图使用场景自身光照；lighting 覆盖与参考图 photo 裁剪尚未实现，会明确返回限制，不伪造图片。
- JSON、GLB 生成可下载文件，记录在 tool-deliveries/<sceneId>/；GLB 通过真实浏览器导出，目前纹理使用外部引用，需要离线纹理时还须保留引用资源。原生无渲染服务器仍如实返回 not_implemented。
- 聊天撤销/重做保留最近30次图编辑，可跨轮次和重启；与手动编辑历史分开。恢复前比较完整图和版本，恢复后回读比对，存在其他修改时不覆盖。记录在 scene-journals/。
- 模型每次生成默认最多等待10分钟，LOCAL_MODEL_TIMEOUT_MS 可调整；用户停止仍立即取消后续调用。一轮最多32次模型往返。首次完整工具定义会增加本机模型预填充耗时，复杂代码仍可能超时或输出截断；不是每个任务都能一次完成。
- 验收矩阵：full-tools-tests/TOOL-MATRIX.md；原始调用、失败与复测记录：full-tools-tests/。成功调用仅覆盖所列测试输入，不代表全部高级参数组合均经过验证。
