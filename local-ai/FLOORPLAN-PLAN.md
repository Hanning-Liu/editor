## 完成结果

五步已完成。接入范围是本地 Studio 生成的 TRELLIS.2 和 Qwen＋Blender 家具。

- 生成链路：最终 GLB → Blender 透明正交俯视 PNG → `floorplan.json` → 资产 `floorPlanUrl` → 原生 2D 渲染器。保留原有缩略图、尺寸、GLB、材质和可编辑源文件。
- 新资产在成功发布前自动生成俯视图；旧资产使用 `node studio/backfill-floorplans.mjs` 回填。按 GLB 哈希及投影版本缓存，脚本会保存迁移前快照和逐场景读回记录。
- 当前两份旧家具已回填；真实新生成并应用 Qwen 非对称长凳、TRELLIS 长凳、Qwen 圆桌。五份资产均实际点击 2D/3D、拖动、旋转 0/45/90 度、等比缩放 1.25、独立轴缩放 `[1.5, 1.1, 0.8]`、刷新并读回。
- 独立轴缩放时，俯视 PNG 与 3D 占地一起变形；圆桌透明角落保留。实际导出渲染场景 GLB，与 SVG 占地边界比较，五份资产最大误差约 0.00000262 米。
