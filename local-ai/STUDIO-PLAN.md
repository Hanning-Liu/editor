## 接入边界

Studio 是本地宿主层的扩展，不修改 Pascal 官方在线服务。网页和本地 MCP/Chat
共同调用同一 Studio 队列；生成不改场景，应用复用原生 `paint`、
`set_zone_intent`、`place_items` 操作。材质通道在 core schema 和 viewer 同步扩展。
官方云端 Architect 的生成、积分及私有服务不在此本地接入范围内。

开发模式另有原编辑器的 React/drei Html 卸载诊断：打开 Studio 前已出现两条，打开 Studio 未新增；本轮未修改第三方库。细节见 `studio-tests/console-diagnostics.json`。
